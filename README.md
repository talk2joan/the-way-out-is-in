# 出路是心路 | the way out is in · 正念书写

一个自包含的单页静态网站，用于「正念书写」主题的沉浸式阅读与书写体验。

## 特点

- **零依赖单文件**：全部样式与脚本内联在 `index.html` 中，无需构建、无外部资源请求。
- **暖纸质感视觉**：克制的纸张纹理、衬线中文字体与暖金/朱砂配色。
- **响应式**：适配移动端与桌面端（`viewport-fit=cover`）。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录启动一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 部署

纯静态站点，可直接托管到 GitHub Pages、Vercel、Netlify 等任意静态平台。
